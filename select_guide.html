SELECT_tb.v 逐行代码深度解析

用于验证脑机接口多设备通信中的地址识别与数据选通模块（SELECT）：内建 4 位计数器 CLK25_divider 生成四分频使能脉冲 CLK25，在 ENABLE 有效窗口（2μs ~ 28μs）内根据 ADDRESS 与 TYPE 控制并/串地址及数据路由输出。

t = 0 ~ 450 μs
精妙的时序衔接设计：
1. t = 0 ~ 300ns：POR = 0 全局复位；同时 ADC_state = 1 持续按住分频器 CLK25_divider 的复位端 RST，确保计数器静止在 cnt4 = 0。
2. t = 1000ns (1μs)：ADC_state 下降为 0，释放分频器复位，CLK25 开始每 4 个主时钟输出一个单周期高脉冲。
3. t = 2000ns (2μs)：在 CLK25 已经稳定运行 1μs 后，ENABLE 拉高为 1 并维持到 28000ns (28μs)，供 SELECT 状态机完成地址串行化（S_ADDRESS）、并行地址锁存（P_ADDRESS）以及命令控制字（comcon_out）选通输出。
