COM_ENABLE_tb.v 逐行代码深度解析

用于验证脑机接口芯片上行通信使能控制器（COM_ENABLE）：监测模拟前端 ADC_state 采样状态，在每次 ADC 转换结束后经过 def_delay（250）与 DELAY（5）设定的防冲突延迟，安全开启 ENABLE 通信窗口并输出分频时钟 CLK25。

📊 COM_ENABLE 硬件功能与绝对时间激励图解

仿真时长 > 1.92 ms
为什么上行通信必须避开 ADC_state == 1？
植入式神经记录芯片的 ADC 在对微伏级神经动作电位进行高精度采样时，数字总线的高速翻转会通过衬底或电源耦合引入开关噪声。COM_ENABLE 模块通过监测 ADC_state 下降沿（采样结束），等待 def_delay（250 周期）与 DELAY（5）设定的稳定时间后，才拉高 ENABLE 通知后端 SELECT 与 COM_CON_OUT 开始向外发送数据。
Verilog 关键语法点：initial fork ... join 与 initial begin ... end 的区别
本测试平台大量使用 initial fork ... join（并行块）：块内所有带延迟的赋值语句均同时在 t = 0 启动计时，因此 #100000、#200000、#920000 均代表绝对仿真时刻（100μs、200μs、920μs），而非相邻语句的累加延迟！
